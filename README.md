An ordered map and set based on a trie.

WORK IN PROGRESS.

One trie to rule them all, one trie to find them,
One trie to bring them all, and in the darkness bind them

Meant to be: Highly general and customizable.

You can see the documentation here: https://docs.rs/trie/latest/trie/.

To use `trie`, add this to `Cargo.toml`:

```toml
[dependencies]
trie = "0.3"
```
